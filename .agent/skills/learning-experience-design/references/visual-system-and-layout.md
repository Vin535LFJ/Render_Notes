# 视觉系统与页面布局配方

> 本文给**面向 Render_Notes 具体页面原型的布局配方**，引用 `design-system.md` 的 token，不重列色板/字号表。

## 1. 版心与栅格
- 正文阅读宽度沿用现有基线（正文 15px / 1.75 行高），不随意改动（这是 Reflex 硬规则）。
- 桌面布局：左侧栏 286px（导航）+ 主内容 + 右侧 TOC 238px；窄屏按 `responsive-design.md` 折叠。
- 栅格只用于对齐，不用于制造"卡片墙"。

## 2. TOC 落位
- 长文（>3 屏）右侧固定 TOC，滚动高亮当前章节；TOC 由标题层级自动生成，不手写。
- 移动端 TOC 收进可展开抽屉，默认收起。

## 3. 教材页的节奏
按"问题 → 前置 → 直觉 → 概念 → 推导 → 工程 → 实践 → 小结 → 承接"分段，每段有视觉分隔（留白或小标题），不用统一卡片。图/公式/代码按语义落位：
- 图紧跟其解释段落，不集中堆在文末；
- 公式单独成块、编号、前后留白；
- 代码块宽度受限、可滚动。

## 4. 技术推导页
- 公式与变量说明同屏；变量表紧随推导。
- 数值算例用对比表或分步块，让读者能跟着算。
- 避免一屏塞多个大公式（外在负荷过高）。

## 5. 交互实验页
- 上部：实验目标 + 前置原理链接；中部：操作区 + 实时反馈；下部：观察记录 + 原理关联。
- 操作区与控制说明紧邻，不让用户上下找控件说明。

## 6. 知识图谱页
- 主视图 + 筛选面板（按主题/先修/学习路径）；节点详情侧栏。
- 首屏给"从哪里开始学"的入口，不是一张无差别的网络图。

## 7. 研究报告页
- 顶部元信息（来源、证据、争议、结论、时间）一眼可见；正文按证据-分析-结论组织。
- 争议与局限要显式呈现，不藏在脚注。

## 8. 术语页
- 定义唯一来源 glossary.json；页面只做呈现 + 示例 + 易混淆对比 + 关联知识。
- 同一术语的别名统一收敛到一个权威条目。

## 9. 明暗主题
- 沿用 `web/assets/styles.css` 的 CSS 变量体系；任何新增样式用变量，不硬编码色值。
- 图表（Mermaid/KaTeX）在明暗两主题都要可读。

## 10. 与旧的 visual-quality-gates 的关系
本文是"怎么排"，`visual-quality-gates.md` 是"排完怎么判定合格"，`ux-review-checklist.md` 是"逐项签发"。三者构成 布局配方 → 门槛定义 → 签发 的链。
