# 学习旅程级交互模式

> 本文管**跨页面/跨章节的学习流程**。组件级微交互（按钮态、hover、工具提示）见旧 `interaction-patterns.md`，本文不重复。

## 1. 课程入口与目标
- 课程首页先回答三个问题：这门课解决什么问题、学完能做什么、需要什么基础。
- 学习目标用可验证的动词（"能画出…"、"能解释…"），不用"了解/掌握"这类不可测表述。
- 数据绑定：`tools/course.json` 的 units/lessons/objectives，不另建内容库。

## 2. 前置知识检查
- 每篇教材开头列出先修课（prerequisites），链到对应课时而非泛泛描述。
- 提供"我还不熟"的快速回退入口，避免读者卡在不懂的术语上。
- 前置关系来自 `knowledge-model/` 与 course.json 的依赖声明。

## 3. 学习路线图
- 用一个可视化的路线图展示当前位置、已完成、接下来，标明分支（哪些是可选深入）。
- 路线图不是装饰性进度条，要能点击跳转到对应课时。

## 4. 上一章 / 下一章承接
- 每篇结尾有明确的"本篇解决了什么 → 下一篇为什么需要它"的桥接段。
- 承接文字来自教材正文的章节桥接（research-to-learning 要求），页面只负责呈现，不重写内容。

## 5. 章节阅读进度
- 进度基于实际阅读位置（scroll/章节锚点），不是虚假的"已读"标记。
- 进度状态存 localStorage，不上传、不制造学习记录假象。

## 6. 重点概念提示
- 在正文侧栏或行内标出本篇的核心概念，链到术语表。
- 概念提示数量克制（3–5 个），多了等于没有。

## 7. 术语快速解释
- 术语首次出现给出行内速解（hover/点击），完整定义链到 `tools/glossary.json` 驱动的术语页。
- 术语定义唯一来源是 glossary.json，页面不复制定义正文。

## 8. 公式与代码的阅读体验
- 公式（KaTeX）字号不小于正文、可横向滚动不截断、长推导分步展示。
- 代码块有语言标注、可复制、长行不撑破布局、明暗主题都可读。

## 9. 交互实验入口
- 教材在讲到对应机制处给出"去做实验"的入口，链到 `labs.json` 对应实验，并说明实验验证的是哪个目标。
- 实验页有操作区 / 实时反馈 / 步骤 / 观察结果 / 原理关联五要素，缺一不可。

## 10. 学习自测
- quiz 每道题挂接断言（claim_ids），答完给出"你验证了哪个知识点"的反馈，不只是对错。
- 自测数据来自 `quizzes/*.json`。

## 11. 知识图谱探索
- 图谱页支持按概念搜索、高亮先修/后继、沿学习路径过滤，而不是只展示一张复杂网络图。
- 节点点击链到对应教材/术语，数据来自 `tools/graph.json`。

## 12. 反馈与学习记录
- 反馈入口沿用现有 feedback UI（localStorage 队列 + JSON 导出），不另建数据库。
- 不制造"已完成 X 门课"类的虚假成就感记录。

## 与质量门槛的关系
上述 12 项中，**6/8/9/10** 涉及 Floor（公式/代码可读、实验可操作、自测不丢断言）；其余主要属 Reflex/Finish。逐项签发见 `ux-review-checklist.md`。
