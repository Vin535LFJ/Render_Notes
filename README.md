## 项目定位

**适合用来**：

- 系统补齐音视频播放、OpenGL/Vulkan、3D 渲染与 GPU 性能优化
- 准备图形/渲染/车载座舱方向的技术面试
- 把零散的项目经验整理成"可解释、可量化、可追问"的知识结构

**不是**：

- 不是 API 手册，不追求覆盖所有函数签名
- 不是跑得起来的工程模板（可运行 demo 仍在缺口清单中）
- 不是绝对正确的权威结论；所有数字与平台行为都带验证状态

**图形实验室**（快捷键 `L`）把教材里的关键原理做成可操作的实验，已有三个端到端示范模块（文档 → 课时 → 术语 → 公式 → 交互 → 自检）：

- **坐标变换与 MVP**（L13 / 任务一）：拖动平移 / 旋转 / 缩放 / FOV / 相机距离，切换透视与正交投影，实时看矩阵、裁切与屏幕投影同步变化；逐阶段追踪一个顶点从模型空间到屏幕像素。
- **程序化几何 · 旋转曲面生成**（L17 / 任务二阶段 1）：切换圆柱/花瓶/球冠/双曲面轮廓，调径向分段、轮廓采样、半径与旋转，实时看顶点缓冲、索引缓冲与三角形数如何生成。配套知识文档 [程序化几何与旋转曲面](07-3D渲染与算法实现/程序化几何与旋转曲面.md)。
- **PBR 光照与材质**（L18 / 任务二阶段 3）：调光源方位/仰角/强度与 albedo / metalness / roughness，Canvas 2D 逐像素算 Cook-Torrance，实时显示 D/G/F 与镜面/漫反射读数；标注为**教学近似**，不是物理精确渲染器。
- 画布由本地 Canvas 2D 绘制（含齐次裁剪），不依赖 Three.js / WebGL / 网络；任务勾选与自检展开状态保存在浏览器本地。
- 实验与教材双向关联：课时可直接进入对应实验，实验页可回到课时与原始文档，文档顶部也会显示配套实验。
- 实验配置来自 [`tools/labs.json`](tools/labs.json)；每个实验用 `type` 区分渲染器（`mvp` / `lathe` / `pbr`），扩展新实验只需追加数据并实现对应的渲染逻辑。

## 学习路径（8 层递进）

1. **基础概念层**：采样/像素格式/容器编码/时间戳/坐标系与矩阵
2. **数据流与时序层**：Demux → Decode → Render，音画同步；流媒体/ABR/HDR/相机采集
