# 课程蓝图：一帧视频如何从文件抵达屏幕

> 对应方案里的 Curriculum Blueprint。此文件是**人工审核关卡 G2** 的对象，须由人确认后才算通过；AI 不得自批。
>
> 状态：待人工审核（G2）。

## 1. 适合的学习者

- 对音视频播放或图形渲染有初步接触，但从未把"MP4 到屏幕"串成一条完整链路。
- 能读懂基础代数；不需要 H.264 编解码或 Vulkan 经验。
- 典型场景：转岗渲染/播放的工程师、准备车载渲染面试的候选人。

## 2. 学习前提

- L00 知识地图（了解 L0–L7 分层）。
- 基础代数（矩阵乘法）；像素与帧的朴素概念。

## 3. 最终学习目标

学完后，学习者能够：

1. 画出"文件 → 解封装 → 解码 → 纹理桥 → GPU 管线 → 帧缓冲 → 屏幕"的端到端链路，并标出每段的数据形态。
2. 解释为什么视频用 YUV420、stride 为何存在、DTS/PTS 为何分叉。
3. 说清零拷贝省掉的是哪段搬移、OES 到 Effect Pass 的转换、PC 独显与移动 SoC 的通路差异。
4. 判断何时该用 RenderGraph，并说明 Pass 与 FBO 特效链的关系。
5. 推导 MVP 组合顺序，处理 NDC/Y-flip 的跨 API 差异。

## 4. 完成后的能力

- **能讲**：60 秒内把一帧画面的旅程讲成因果链，而非散落名词。
- **能查**：遇到"术语突然冒出来"时，知道它属于哪一层、为什么现在引入。
- **能做**：在交互实验里调参数、观察数值、解释现象。

## 5. 知识范围

- 覆盖：像素格式、时间戳、纹理桥、零拷贝、RenderGraph、坐标变换。
- 不覆盖（本 pilot）：编解码算法细节、色彩管理完整推导、光追、Shader 变体系统。边界见[知识缺口登记表](../../00-导航与索引/知识缺口登记表.md)。

## 6. 学习路线

```
L01 像素形状 → L02 时间顺序 → L06 数据进 GPU → L11 多 Pass 组织 → L13 数学根基
```

每课：钩子 → 前置 → 概念（引用主文档锚点）→ 实验 → 自测 → 桥。完整章节结构见 `course.json` 与 `lessons/`。

## 7. 实践项目

贯穿五个交互实验：`yuv-to-rgb`、`pts-dts-timeline`、`frame-pipeline`、`rendergraph-dag`、`transform-mvp`。实验定义只在 `tools/labs.json`，本课程不复制。

## 8. 考核方式

- 每课 3 题形成性练习（`quizzes/*.json`），题目回指 claim ledger。
- 终结性任务：不看文档复述端到端链路，并在知识依赖图上指出每环的层次归属。
- 门槛：见 `review-report.md`（总分 ≥85，事实与连贯性各 ≥80）。
