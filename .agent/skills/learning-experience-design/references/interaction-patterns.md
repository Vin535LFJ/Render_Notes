# Interaction Patterns（学习交互模式）

> 12 项学习体验能力的交互约定。全部绑定现有数据，不另建内容库。

## 1. 课程入口与目标
- 课程首页给"你会学到什么/适合谁/前置要求"，来自 `course.json` 的 units 与 lessons objectives。

## 2. 前置知识提示
- 章节顶部列 prerequisites（来自 lesson frontmatter），可点击跳转到对应课；缺失前置给"先修未满足"提示。

## 3. 学习路线图
- 可视化 19 课的主线与支线（L13/L14），当前位置高亮；路线按已裁决的 L12→L13 主线。

## 4. 上/下一章承接
- 页尾"下一章桥"链接 + `next` 指针；上一章回看；进度指示（第 n / 共 m 课）。

## 5. 章节阅读进度
- 滚动进度条 + 完成勾选（localStorage，与现有反馈机制一致）；不强制登录。

## 6. 重点概念提示
- 每章 2–4 个核心概念，正文首次出现时轻微强调（下边框/加粗），不滥用高亮块。

## 7. 术语快速解释
- 术语绑定 `glossary.json`：hover/点击展开一行释义；键盘可达；不遮挡正文；不每词都挂。

## 8. 公式与代码阅读
- 公式可复制 LaTeX；代码有复制按钮与语言标签；长内容横向滚动不破坏排版。

## 9. 交互实验入口
- 正文"动手实验"按钮直达 `labs.json` 对应实验（lab 字段）；实验页给"回正文"反链。

## 10. 学习自测
- quiz（`quizzes/<L##>.json`）在章节末尾；即时反馈对错 + 解释；不显示答案直到作答；不自动记录为"已掌握"。

## 11. 知识图谱探索
- 从概念跳转图谱并高亮该节点；图谱节点回知识文章；路径高亮辅助学习顺序。

## 12. 反馈与学习记录
- 沿用现有 `tools/report_feedback.py` + localStorage 队列 + JSON 导出；反馈入口在章节页脚；不新增账号体系。

## 交互通用规则
- 所有交互键盘可达（Tab/Enter/Esc），焦点可见。
- 尊重 `prefers-reduced-motion`。
- 移动端触摸目标 ≥44px；控件不遮正文。
- 不改变现有 7 个实验的渲染逻辑，只优化入口与说明。
