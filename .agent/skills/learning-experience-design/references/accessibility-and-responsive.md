# 无障碍与响应式联合回归

> 本文是**合并的联合验收流程**（WCAG AA + 四档宽度 + 明暗主题 + 键盘 + 特殊内容）。基础概念见旧 `accessibility.md` / `responsive-design.md`，本文给的是"怎么一起测、怎么判过"。

## 1. 四档宽度矩阵
| 宽度 | 设备 | 必查 |
|---|---|---|
| 360px | 手机 | 正文不横向溢出、侧栏收起、TOC 抽屉、代码块可滚动、实验可操作 |
| 768px | 平板 | 双栏折叠正确、表格不溢出、图可读 |
| 1024px | 小桌面 | 三栏布局完整、TOC 不遮挡正文 |
| 1440px | 桌面 | 阅读宽度不过宽、留白合理 |

每档在**明暗两个主题**各截一张图，共 8 张；长文页、公式页、代码页、Mermaid 页、实验页各跑一遍矩阵。

## 2. 无障碍硬指标（WCAG AA）
- 正文对比度 ≥ 4.5:1；大字号 ≥ 3:1。用工具实测，不靠肉眼。
- 所有交互元素可键盘到达（Tab），有可见 focus 样式，Enter/space 可激活，Esc 可关闭浮层。
- 图片/图表有 alt 或等价文本；Mermaid 图有文字描述。
- 标题层级语义正确（h1→h2→h3，不跳级）。
- 表单/实验控件有 label，错误提示可访问。

## 3. 键盘专项
- 仅用键盘走完：打开课程 → 定位章节 → 展开术语速解 → 打开实验 → 操作 → 提交 → 查看反馈。
- Tab 顺序与视觉顺序一致；无键盘陷阱。
- 跳到主内容（skip link）存在且有效。

## 4. 特殊内容溢出检查
- KaTeX 公式：长公式可横向滚动，不撑破版心；行内公式不破坏行高。
- 代码块：长行可滚动、有语言标注、复制按钮可达。
- Mermaid：宽图在窄屏可滚动或缩放，节点文字可读。
- 表格：窄屏可横向滚动，表头保留。

## 5. 主题切换
- 切换后所有元素（含图表/公式/代码）颜色正确，无残留浅色/深色块。
- 主题偏好持久化到 localStorage，刷新后保持。

## 6. 判定
- 上述任一项失败 = Floor 阻塞（见 `ux-review-checklist.md`），不得发布。
- 无浏览器实测证据（截图/对比度读数/键盘路径记录）不得声称通过。
- 工具：真实浏览器渲染 + 截图；`py -3 .agent/skills/learning-experience-design/scripts/check_visual_floor.py` 只能做静态预检，不能替代实测。

## 7. 与回归清单的关系
本流程的执行记录填入 `assets/visual-regression-checklist.md`；签发结论进入 `ux-review-checklist.md`。
