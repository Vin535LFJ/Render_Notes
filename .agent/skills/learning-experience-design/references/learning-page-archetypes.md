# Learning Page Archetypes（学习页面原型）

> 不同内容用不同布局。禁止所有页面一个模板。数据全部来自现有 `course.json`/`glossary.json`/`labs.json`/`graph.json`/`evidence/`，不另建内容库。

## A · 知识文章（Knowledge Article）
- **目标**：查漏补缺、理解单个知识点。
- **结构**：问题钩子 → 定义 → 直观例子 → 原理 → 与其他知识的关系 → 来源引用 → 术语。
- **必备**：前置概念链接、来源/断言状态、相关概念图谱入口。
- **反模式**：把它写成教材章节（过长）或术语条目（过短）。

## B · 系统教材（Systematic Lesson）
- **目标**：完成一个认知闭环，学完能做原来不会的事。
- **结构**：学习目标 → 问题引入 → 前置知识 → 直观理解 → 概念建立 → 因果推导 → 数学/工程机制 → 实践验证 → 知识迁移 → 下一章承接。
- **必备**：章节进度、上/下一章导航、自测、实验入口、claim 挂接。
- **反模式**：把核心原理外包给"去看别的文档"，本章不自洽。

## C · 技术原理推导（Derivation）
- **目标**：看懂"为什么"，能自己推一遍。
- **结构**：问题与假设 → 变量定义 → 分步推导（每步一句理由）→ 数值算例 → 工程意义 → 常见错误。
- **必备**：公式可滚动、变量表、每步解释；透视除法/坐标变换类内容在此原型。
- **反模式**：一次性甩出最终公式；只给符号不给物理意义。

## D · 交互实验（Interactive Lab）
- **目标**：动手验证理解，观察参数变化的结果。
- **结构**：实验目标 → 前置概念 → 操作区（控件）→ 实时反馈区 → 分步任务（来自 labs.json tasks）→ 观察记录 → 自测（selfTest）→ 关联原理。
- **必备**：操作区与反馈区同屏可见、可键盘操作、重置按钮、结果可解释。
- **反模式**：控件与结果分离导致看不到因果；实验与正文无关联。

## E · 知识图谱（Knowledge Graph）
- **目标**：探索概念关系、找到学习路径，不是展示复杂网络。
- **结构**：入口说明 → 重点节点 → 依赖关系 → 推荐学习路径 → 节点详情 → 筛选/搜索。
- **必备**：高亮当前节点、路径高亮、点击进知识文章、图例。
- **反模式**：一张巨大网络图无交互；节点无说明。

## F · 研究报告（Research Report）
- **目标**：了解研究结论的可信度与边界。
- **结构**：研究范围/方法 → 来源 → 关键发现 → 证据与断言 → 争议 → 局限 → 结论 → 未解决问题 → 研究时间。
- **必备**：来源可追溯、断言状态标注、争议与局限不隐藏。
- **反模式**：把 AI 生成内容当已验证结论；隐藏反例。

## G · 术语与概念（Glossary / Concept）
- **目标**：快速理解一个术语的定义、背景、易混点。
- **结构**：一句话定义 → 背景 → 示例 → 易混淆概念对比 → 关联知识 → 术语表来源。
- **必备**：定义唯一来源为 `glossary.json`；跨章递进（直观→原理→数学→架构→实践）。
- **反模式**：多章重复同一术语定义却不递进；在正文另造词典。
