# Responsive Design（响应式设计）

> 断点：360 / 768 / 1024 / 1440 px。沿用 `web/assets/styles.css` 现有变量与布局，不重写三栏架构。

## 断点行为

| 宽度 | 布局 | 侧栏 | TOC | 正文 |
|---|---|---|---|---|
| ≥1280px | 三栏（导航/正文/TOC） | 展开 286px | 展开 238px | 限宽居中 |
| 1024–1279px | 两栏（导航/正文） | 展开 | 隐藏 | 限宽居中 |
| 768–1023px | 单栏 + 可折叠导航 | 抽屉 | 隐藏 | 全宽减内边距 |
| <768px（含 360） | 单栏 | 汉堡抽屉 | 隐藏 | 全宽减内边距 |

## 规则
1. **正文优先**：任何断点都不让侧栏挤压正文到不可读。
2. **横向溢出**：代码块、公式、表格、Mermaid 图在小屏用 `overflow-x:auto`，不撑破页面。
3. **触摸目标**：按钮/链接 ≥ 44px；相邻可点元素间距足够。
4. **导航折叠**：窄屏侧栏转抽屉，可关闭（Esc/遮罩点击），焦点管理正确。
5. **表格**：窄屏可横向滚动；复杂对比表在极窄屏考虑转卡片，但不丢数据。
6. **图**：Mermaid 图小屏可滚动或点击放大；不缩到看不清。

## 验证
- 每档宽度真实浏览器截图（360/768/1024/1440），明暗主题各一组。
- 检查：无横向溢出、无内容截断、导航可用、实验可操作、键盘可达。
- 200% 缩放等效窄屏行为。

## 反模式
- 小屏强行塞三栏导致正文只剩几百像素。
- 固定宽度图片/表格撑破视口。
- 隐藏"不重要的"操作——移动端用户同样需要实验与自测。
