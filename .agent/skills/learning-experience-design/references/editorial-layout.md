# Editorial Layout（编辑式排版）

> 目标：让长篇技术内容像深度研究杂志一样可读，而不是文档树或卡片墙。

## 版式原则
1. **阅读优先**：正文栏有稳定宽度与行高；装饰让位于文字。
2. **层级靠排版建立**：用字号、字重、留白、分隔线表达层级，不用彩色卡片堆叠。
3. **节奏变化**：长文每 3–5 屏插入一个视觉锚点（图/表/引用/推导块），打破纯文字疲劳，但不无意义装饰。
4. **留白是内容**：章节间留白大于段落，段落间大于行内。

## 长文结构
- 引言设"本章回答"钩子 → 问题引入 → 直观认识 → 原理逐层 → 数学/数据 → 工程应用 → 常见误区 → 实验 → 总结 → 自测 → 下一章桥。
- 章节开头给"你将能…"的学习目标；结尾给可复述的主动回忆问题。

## 编辑式元素
- **导语/摘要块**：章节开头一段深色/软背景引言，点明问题与价值。
- **旁注（margin note）**：补充条件、⚠️限定、术语quick释义，放侧栏不打断主线。
- **引用块**：来源与断言状态用统一样式，视觉上区别于正文。
- **推导块**：公式分行、变量标注、每步一句解释。
- **对比表**：并列方案/API 差异用表格，不用两段散文。

## 反模式
- 每个标题上方一条 eyebrow 小标签（Hallmark 反 slop 项）。
- 追踪字距的全大写标签滥用。
- 标题里染一个彩色单词。
- 一整页只有空卡片框或只有图片。
- 正文行宽过宽（>80 字符）或过窄（<45 字符）。
- 跨度大的渐变背景、玻璃拟态堆叠。

## 与页面原型的关系
编辑式排版是"怎么说"，页面原型（`learning-page-archetypes.md`）是"说什么、按什么结构说"。先定原型再套排版。
