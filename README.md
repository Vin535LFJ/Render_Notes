## 学习路径（8 层递进）

1. **基础概念层**：采样/像素格式/容器编码/时间戳/坐标系与矩阵
2. **数据流与时序层**：Demux → Decode → Render，音画同步；流媒体/ABR/HDR/相机采集
3. **API 与实现层**：FFmpeg、MediaCodec、OpenGL ES、Surface 体系
4. **优化与调试层**：DrawCall、纹理压缩、FBO、零拷贝、功耗/延迟
5. **3D 与算法层**：变换矩阵、PBR/阴影、GPU 图像算法、批处理
6. **工程架构层**：多路播放器、跨平台渲染抽象、RenderGraph、显式 API
7. **项目实战层**：testKTX → GPU_Native-Runtime 演进
8. **面试冲刺层**：车载渲染方向速问速答 + 八篇专项文档（见 [学习路径指南](00-导航与索引/学习路径指南.md)）
